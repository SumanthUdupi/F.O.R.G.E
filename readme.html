THE BRAIN

Every agent framework grows a chief executive. This one refuses to.

A single orchestrator routes badly (no portfolio), can't be audited (one stream of reasoning), and hides its mistakes (no second seat with standing to object). F.O.R.G.E. is governed by six accountable seats: every decision has an owner, every bad decision has a dissenter on the record, and a deadlock escalates to you — because a deadlock is information. Each seat declares in writing what it refuses to do and what it will object to; the audit fails any seat without both.

The Chair

Convenes, sequences, records. The plan, the minutes, the escalation you actually see.

REFUSES to break a tie — a deadlocked board comes to you, never gets chaired away.

Chief of Works

Engineering, QA, Release, Interface — whether what was built is correct and actually verified.

REFUSES "done" with no matching evidence.

Chief of Ledger

The burn, the attribution, whether a stage earned its cost.

REFUSES to trade correctness for tokens.

Chief of Workforce

Who is trusted with what — measured from outcomes, never assumed.

REFUSES to retire an agent before its knowledge is extracted.

Chief of Intent

Your request into requirements; sixteen handoffs into one readable brief.

REFUSES to guess at a missing requirement.

Chief of Memory

What the organization knows, how confident it is entitled to be, and when that decays.

REFUSES to answer from memory when the memory is stale.

HOW A REQUEST FLOWS

Same request, same plan, every time — and it prices itself first.

No model composes the plan. Fixed rules staff specialists by measured reliability, batch work by write-scope so writers never collide, refuse any plan that writes without verifying, and estimate the cost from this workspace's own history before anything runs.

THE LEARNING LOOP

The tenth campaign is staffed better than the first — and you sign every change.

work happens→ outcomes land in an append-only ledger→ reliability is derived, smoothed→ routing shifts→ the org proposes adaptations→ you approve→ reversible, always
0.708 → 0.111

One agent's score after five recorded failures — and it loses the next stage to a colleague. No model decides this; it is arithmetic over the ledger, and three lucky runs never read as skill.

2 corrections → 1 rule

Correct the same agent twice and the organization drafts a standing instruction for that workspace. Approve once; withdraw any time by deleting a block. It can never touch its own constitution, registry or code — enforced, and tested by attack.

WHAT IT REFUSED TO BECOME

Six repos were cloned and dissected. Judgment is a feature.

Spend-measurement from transcripts (studied in codeburn) and token discipline in every contract (studied in caveman) came in, rebuilt with zero dependencies. Cost-aware planning came from OmniRoute's idea — without its gateway. Paid compaction, resident proxies and a 314-tool swarm platform were refused, each with the reason on record. The full verdicts: docs/STUDIES.md.

GET IT RUNNING

Three commands. Node 18+. No npm install, ever.

  1. Clone and audit

    git clone https://github.com/SumanthUdupi/F.O.R.G.E && cd F.O.R.G.E && node scripts/forge.mjs doctor — the constitutional audit runs on a machine that has never seen this repo.

  2. Install the organization

    node scripts/forge.mjs install --apply --hooks — 64 agents, the /forge skill, and the two hooks that make it engage on every prompt. Merges your settings; never clobbers a file it didn't write.

  3. Open the Console

    node scripts/forge.mjs deck — then type /forge in your next Claude Code session and give it something real.
