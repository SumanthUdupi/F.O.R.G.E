THE BET

Every agent framework grows a chief executive. This one refuses to.

A single orchestrator routes badly because it has no portfolio, cannot be audited because its reasoning is one stream, and hides its mistakes because no second seat has standing to object. Six accountable seats mean a decision has an owner, a bad decision has a dissenter on the record, and a deadlock goes to you — because a deadlock is information.

Chair of the Board

The Campaign Vector, the minutes, the escalation you actually see.

REFUSES to break a tie between two seats — a deadlock is escalated, never chaired away.

Chief of Works

Whether what was built is correct, maintainable and actually verified.

REFUSES a claim of "done" with no matching evidence.

Chief of Ledger

The burn, the attribution, whether a stage earned its cost.

REFUSES to trade correctness for tokens.

Chief of Workforce

Which agents are trusted with what — measured, not assumed.

REFUSES to retire an agent before its knowledge is extracted.

Chief of Intent

Request into requirement; organization into one readable brief.

REFUSES to guess at a missing requirement.

Chief of Memory

What the organization knows, and how confident it is entitled to be.

REFUSES to answer from memory when the memory is stale.

GET IT RUNNING

Three commands. No npm install, ever.

  1. Clone and audit

    git clone https://github.com/SumanthUdupi/F.O.R.G.E && cd F.O.R.G.E && node scripts/forge.mjs doctor — the constitutional audit runs on a machine that has never seen this repo. Node 18+ is the only requirement.

  2. Install the organization

    node scripts/forge.mjs install --apply --hooks — 64 agents, the /forge skill, and the two hooks that make it engage on every prompt. Merges your settings; never clobbers a file it didn't write.

  3. Open the Console

    node scripts/forge.mjs deck — warm, plain-language mission control on loopback: chat with any agent, queue ideas and repos for study, approve adaptations, watch spending and recognition. The technical everything-on-one-screen view retired; this is the only surface, on purpose.
